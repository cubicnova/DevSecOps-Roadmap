# False Positive Triage Checklist

- [ ] Read the rule description and query help.
- [ ] Confirm the exact location, branch, and affected commit.
- [ ] Identify source and sink.
- [ ] Trace all relevant transformations and branches.
- [ ] Verify sanitizer and validation semantics.
- [ ] Check reachability and attacker control.
- [ ] Assess exploitability and impact.
- [ ] Distinguish false positive from accepted risk.
- [ ] Record evidence and reviewer.
- [ ] Fix, dismiss, escalate, or document risk.
- [ ] Add regression tests or query-model improvements.
- [ ] Rerun analysis and update the audit trail.
